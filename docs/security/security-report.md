## Input and effect tracing

[skill-universe](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/skill-universe) dispatches only a fixed command allowlist and passes quoted arguments to command files. [commands/init.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/init.sh) converts harness names into fixed defaults using jq, writes a new manifest with noclobber and initializes the upstream upgrade source. [commands/install.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/install.sh) passes URL/branch to Git, hashes URL plus branch into a checkout identifier, validates the source tree and aliases, records backups, creates symlinks and updates JSON via jq arguments. Skill/rule bytes are never evaluated by the distributor.

[commands/list.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/list.sh) reads only the manifest; [commands/version.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/version.sh) prints VERSION; [commands/help.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/help.sh) prints literal help. [commands/rename.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/rename.sh) and [commands/remove.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/remove.sh) select registered items and require exact original link targets. [commands/update.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/update.sh) fetches the recorded source, validates candidate tree modes, fast-forwards the shared checkout and updates all associated manifest commit records; [commands/upgrade.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/upgrade.sh) fetches and fast-forwards the configured executable tool source. [commands/common.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/common.sh) establishes private transactions, serializes mutations and rolls ordinary file changes back; Git operations retain recovery state on failure. Both [install.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/install.sh) and [docs/install.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/docs/install.sh) clone the declared upstream tool and create its executable command link. [commands/codex-rules.sh](https://github.com/seliverstov-maxim/skill-universe/blob/67f8e391bcb8604c29afa6074cefcc4c1061dd3a/commands/codex-rules.sh) manages a delimited instruction block without evaluating its text.
