03 / WHAT IT DOES

Install and update skills and rules

Choose an entire repository
or individual items.

01

Choose your harnesses

Use Codex, Claude, or both.

skill-universe init --harness=codex,claude
02

Install skills and rules

Install all skills and rules from its default branch.

skill-universe install <repo-url>
03

Get updates

Update installed skills and rules.

skill-universe update all

SELECT A SKILL

skill-universe install <repo-url> \
  --skill=<skill-name> --branch=<branch>

Omit --branch to use the repository’s default branch.

SELECT A RULE

skill-universe install <repo-url> \
  --rule=<rule-name> --alias=<alias>

Use --alias to avoid name collisions. Skills and rules share one alias namespace.

Items from the same repository URL and branch share a checkout. Updating one updates them all.

Also available: list, rename, remove and upgrade. See all commands ↗.
