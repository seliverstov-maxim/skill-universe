03 / WHAT IT DOES

Configure. Install. Update.

Codex and Claude.
Your repositories. Your skills.

01

Choose your harnesses

Use Codex, Claude, or both.

skill-universe init --harness=codex,claude
02

Install skills

Add a Git repository URL.

skill-universe install <repo-url>
03

Get updates

Update all installed skills with one command.

skill-universe update all

Also supports branch and individual skill selection, custom aliases, renaming, removal, and updating the tool itself.
